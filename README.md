# SemantIAr Juegos

Aplicación Angular independiente para entrenamiento en semántica clínica y razonamiento bayesiano.

Este proyecto no importa el anotador, no lee sus JSON y no comparte el almacenamiento de registros.

## Desarrollo local

```bash
npm ci
npm start -- --host 127.0.0.1 --port 4200
```

Abrir `http://localhost:4200/`.
