Cómo interpretar el juego

El contexto modifica la probabilidad de cada hipótesis

Las barras muestran cuánto apoyo recibe cada concepto antes y después de incorporar las pistas de la nota. La probabilidad previa es el punto de partida; la probabilidad posterior refleja lo que cambia al considerar el contexto.

El índice de incertidumbre semántica (IIS) resume cuán difícil es decidir: un valor bajo indica que una hipótesis se diferencia con claridad; un valor alto indica que varias interpretaciones siguen siendo posibles y que abstenerse puede ser la decisión más rigurosa.

No hace falta conocer la palabra “entropía” para jugar: aquí representa, simplemente, cuánto se reparten las posibilidades entre las alternativas.
